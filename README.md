# java-lotto-precourse

# 기능 요구 사항
- 로또 구입금액 입력 기능
  - 구입 금액은 1000원 단위로만 입력 가능
  - 사용자가 입력하는 값은 camp.nextstep.edu.missionutils.Console의 readLine()을 활용한다.
- 구입 개수별 로또 번호 자동 생성 및 출력 기능
  - 구입금액으로 개수를 구해 자동으로 로또 번호 생성(예: 8000원 → 8개)
    - 개수별 번호 생성시 번호 조합의 일치는 허용
    - 해당 확률은 극히 낮아 고객이 동일한 번호를 받을 가능성은 무시한다.
      - 6개 번호 조합의 전체 경우의 수:
        C(45, 6) = 8,145,060  (약 8.145백만)
      - 6개 + 보너스(=7개) 조합의 전체 경우의 수:
        C(45, 7) = 45,379,620 (약 45.38백만)
C(45, 7) = 45,379,620 (약 45.38백만)
  - 로또 번호는 1~45 사이의 숫자 6개로 구성 및 중복 불가
  - 번호는 오름차순 정렬하여 출력
  - 제약: Random 값 추출은 camp.nextstep.edu.missionutils.Randoms의 pickUniqueNumbersInRange()를 활용한다.
- 당첨 번호/보너스 번호 입력 기능
  - 1~45 사이의 숫자 6개를 당첨 번호로 입력 받는다.
  - 당첨 번호/보너스 번호간 중복 불가
- 당첨 통계 출력 기능
  - 구입한 로또 번호와 당첨 번호를 비교하여 일치한 번호 개수별 당첨 통계를 출력
  - 당첨 금액(3개~6개)
    - 3개 일치 (5,000원)
    - 4개 일치 (50,000원)
    - 5개 일치 (1,500,000원)
    - 5개 일치, 보너스 볼 일치 (30,000,000원)
    - 6개 일치 (2,000,000,000원)
- 총 수익률 계산 기능
  - 구입 금액과 당첨 금액을 바탕으로 수익률 계산
  - 수익률은 소수점 둘째 자리에서 반올림
  - 수익률(%) = (총 당첨금 ÷ 총 구입금액) × 100
- 사용자 입력 값에 대한 예외 처리 기능
  - 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
  - 조건
    - 당첨 번호/보너스 번호가 1~45 사이의 숫자가 아닐 경우
    - 당첨 번호가 중복될 경우
    - 보너스 번호가 당첨 번호와 중복될 경우
    - 구입 금액이 1000원 단위가 아닐 경우
    - 구입 금액이 정수가 아닐 경우(공백, 소수, 문자, 음수 등)
    - 당첨 번호/보너스 번호 입력이 정수가 아닐 경우(공백, 소수, 문자, 음수 등)

```text
구입금액을 입력해 주세요.

보너스 번호를 입력해 주세요.
7
```
